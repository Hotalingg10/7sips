# 7 Sips by Wakeline Media (beta)

Seven quick morning games, one a day. Play at **https://hotalingg10.github.io/7sips/**

This repo only hosts the built game page. It is generated from the 7 Sips build kit
(`beta/work/build.js` then `beta/work/site.js`); don't hand-edit `index.html`.
Player progress saves in each player's own browser on this site.
